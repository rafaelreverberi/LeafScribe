# LeafScribe 0.2.0

The first public release of LeafScribe — a native macOS document export studio.

## Download

**LeafScribe-macOS-arm64.zip** contains the self-contained application for **Apple Silicon Macs running macOS 14 or later**. A separate Python installation is not required. Verify the download with the accompanying `SHA256SUMS` file.

Extract the archive, move LeafScribe.app to Applications, and open it. This is an **early, ad-hoc signed release, not Apple-notarized**; macOS may block the first launch. Review the source and download before deciding whether to allow the app through macOS Privacy & Security. No Intel or macOS 14 hardware validation has been performed.

## Included

- Native SwiftUI library with grid/list views, previews, inspector and export history.
- Local Beook discovery and chapter/section selection.
- EPUB archives and unpacked Apple Books `.epub` package imports, plus HTML and PDF.
- PDF and EPUB export, with searchable PDF text and chapter outlines where supported.
- Beook highlight range recovery, stored colors, anchored text notes and an annotation appendix. Unresolved positions are explicitly retained in the appendix.
- EPUB 2/3 cover discovery, including existing imports; cover sizing preferences for proportional fit or full-frame stretching.
- Native PDF preservation and text-first PDF-to-EPUB with optional Vision OCR.
- Bundled Python helper, offline rendering, staged exports and immutable source files.

## Known boundaries

Complex publisher styles and interactive exercises may differ from the original app. PDF pagination follows the paper format. OCR and annotation recovery need review; no guarantee of pixel-identical output, PDF/A, tagged PDF accessibility or every-publisher compatibility is made. Encrypted EPUB resources, including obfuscated fonts, are rejected.

## Validation

The release was built and checked on an Apple Silicon Mac with macOS 27.2. Swift tests, the LeafScribe engine suite, and the isolated upstream suite were run. Graphical bundle verification exercises the actual packaged helper, searchable PDF, EPUB round-trip, PDF preservation, OCR and layout fixtures. See docs/VALIDATION.md for the scope of each check.
